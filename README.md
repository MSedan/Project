# Duck Page

Hello!

This is my final project for the Code First Girls (CFG) Web Development course.

My website is all about ducks and was created using HTML, CSS, JavaScript, and Bootstrap. The aim of the project was to practise front-end web development skills while creating a fun and interactive user experience.

## Features

- Responsive navigation bar
- Interactive flip cards with duck images
- Information about duck habitats
- Information about different duck species
- Bootstrap image carousel
- Dynamic progress bar
- Toast notifications
- User feedback form
- Custom colour palette and styling
- Responsive layouts using Flexbox

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
